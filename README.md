# FF14 スクリーンショット 16:9 エディター

FF14 のウルトラワイドなスクリーンショットを、コピーライト表記付きの 16:9 PNG に整形するブラウザアプリです。

画像は端末内で処理され、外部サーバーへアップロードされません。

詳細な仕様は [設計書](docs/ff14-screenshot-editor-spec.md) を参照してください。

## 使い方

1. PNG または JPEG のスクリーンショットを選択します。
2. 16:9 固定の枠を動かし、残したい範囲を調整します。
3. コピーライト表記・位置・フォントを選びます。
4. 「トリミングして PNG を生成」を押し、表示されたボタンからダウンロードします。

## ローカルでの起動

```bash
npm install
npm run dev
```

## 公開

`main` ブランチへプッシュすると GitHub Actions が GitHub Pages を更新します。初回のみ GitHub リポジトリの **Settings → Pages** で、公開元を **GitHub Actions** に設定してください。
