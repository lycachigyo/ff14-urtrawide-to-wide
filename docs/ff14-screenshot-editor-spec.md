# FF14 スクリーンショット 16:9 エディター 設計書

## 1. 目的

FF14 をウルトラワイドモニター（主に 21:9）で撮影したスクリーンショットを、SNS 投稿やスマートフォンで見やすい 16:9 の PNG 画像へ整形する。

利用者が残す範囲とコピーライト表記を画面上で確認しながら決め、画像を端末内だけで生成・ダウンロードできることを目的とする。

## 2. 利用対象と前提

- 利用対象は PC のブラウザ利用者のみ。スマートフォン・タブレットの表示や操作は対象外とする。
- 画像処理はすべてブラウザ内で行う。画像をサーバーへ送信・保存しない。
- 画面遷移のない、トップページ 1 画面で完結する。
- 入力画像は PNG、JPEG / JPG のみ受け付ける。

## 3. 機能要件

### 3.1 画像の読み込み

1. 利用者は FF14 のスクリーンショットを選択してアップロードする。
2. 正常な PNG、JPEG / JPG の場合、元画像全体をプレビューへ表示する。
3. 非対応形式または読み込めないファイルの場合、理由が分かるエラーメッセージを表示する。
4. 新しい画像を選ぶと、切り抜き・コピーライト設定・生成結果を初期状態へ戻す。

### 3.2 16:9 切り抜き

- プレビュー上へ 16:9 固定の選択枠を表示する。
- 選択枠はドラッグで移動でき、四隅または辺のハンドルで拡大・縮小できる。
- 選択枠の縦横比は常に 16:9 とし、利用者がほかの比率を選択することはできない。
- 選択枠は元画像の範囲を越えない。
- 初期位置は、元画像の中央に収まる最大の 16:9 領域とする。

### 3.3 コピーライト表記

利用者は次のいずれか一つを選択する。

| 表示名 | 文字列 |
| --- | --- |
| コピーライトなし（非推奨） | （表示しない） |
| 簡易表記 | `© SQUARE ENIX` |
| 標準表記 | `(C) SQUARE ENIX CO., LTD. All Rights Reserved` |

さらに次を選択する。

- 配置: 左上 / 右上 / 左下 / 右下
- フォント: 雰囲気の異なる 4 種類

文字色は読みやすい白を基本とし、視認性のため控えめな黒い影を付与する。配置は切り抜き後の画像領域を基準とし、端から一定の余白を取る。

コピーライトなしを選択した場合は、プレビュー・出力画像のどちらにも文字を描画しない。ゲーム側ですでに表記される場合を想定した選択肢だが、権利表記が必要な画像では選ばないことを推奨する。

## 4. 画面仕様

### 初期状態

- タイトルと用途説明
- PNG または JPEG を選択するアップロード領域
- 編集設定とトリミングボタンは非活性

### 編集中

| エリア | 内容 |
| --- | --- |
| プレビュー | 元画像全体、暗く表示した選択範囲外、16:9 の選択枠、コピーライトの仕上がりプレビュー |
| 設定 | コピーライト文言、表示位置、フォントの選択肢 |
| 操作 | 「トリミングして PNG を生成」ボタン |

- 設定変更・選択枠の移動や拡大縮小は即座にプレビューへ反映する。
- トリミングの実行前は、ダウンロードボタンを表示しない。

### 生成完了状態

- 生成済み画像のプレビューを表示する。
- トリミングボタンは非活性にする。
- 「PNG をダウンロード」ボタンを表示する。
- 設定や選択範囲を変更した場合は生成結果を無効にし、再度トリミングボタンを有効にする。

## 5. 画像品質と出力仕様

- 出力形式は PNG 固定とする。
- 切り抜き後の出力解像度は、プレビューの大きさではなく元画像に対応する選択範囲のピクセル数とする。
- PNG は可逆圧縮で出力するため、アプリの出力処理で JPEG のような追加の画質劣化は生じない。
- JPEG 入力画像に元から含まれる非可逆圧縮の品質は回復しない。
- コピーライト文字は出力画像へ直接描画して確定する。ダウンロード後に個別編集することは対象外とする。

## 6. 技術方針

- フロントエンド: React + TypeScript + Vite
- 画像編集 UI: `react-easy-crop` を使い、16:9 固定のドラッグ・拡大縮小操作を提供する。
- 出力: ブラウザの Canvas API で、元解像度の切り抜きとコピーライト描画を行い PNG Blob を生成する。
- フォント: Web フォントを読み込み、プレビューと出力で同じ書体を使う。
- 配布: GitHub Actions で静的ファイルを GitHub Pages へ自動公開する。

## 7. 初期フォント案

| 表示名 | 意図 |
| --- | --- |
| Great Vibes | 華やかな筆記体 |
| Allura | 軽やかな筆記体 |
| Cormorant Garamond | 上品で読みやすいセリフ体 |
| Marcellus | 端正で安定感のあるローマン体 |

実装時は、プレビュー・出力ともに文字の長さに応じて無理なく読めるサイズにする。

## 8. 対象外

- 16:9 以外のトリミング比率
- 複数画像の一括処理
- 画像の明るさ・色・フィルター編集
- 画像のクラウド保存・共有機能
- モバイル端末向けの操作最適化

- `main` ブランチへ変更を反映すると、GitHub Actions がビルドして GitHub Pages を更新する構成にする。
- 公開後の URL は GitHub Pages の設定で有効化して確認する。
