# FF14 スクリーンショット 16:9 エディター 仕様書

この文書は、FF14 スクリーンショット 16:9 エディターの **v3確定仕様** です。

## 目的

ウルトラワイドモニターで撮影したFF14のスクリーンショットを、SNSで扱いやすい横16:9または縦9:16のPNG画像へ整形する。

## 対象範囲

- PCのブラウザで利用する。
- 画面遷移なしの1画面で完結する。
- 画像はブラウザ内だけで処理し、外部へ送信・保存しない。
- 入力形式はPNG、JPEG / JPGとする。
- 出力形式はPNGとする。
- アクセス状況の把握にはGoogle Analyticsを利用する。閲覧に関する計測情報はGoogle Analyticsへ送信するが、利用者が読み込んだ画像データは送信しない。

## 画像の読み込み

- 利用者は画像を選択、またはアップロード領域へドラッグ＆ドロップして読み込む。
- ドラッグ中はアップロード領域の見た目を変え、ドロップできることを示す。
- 対応していない形式や読み込めない画像には、理由が分かるメッセージを表示する。
- 別の画像を選択すると、切り抜き範囲と生成結果をリセットする。

## トリミング

- 元画像の全体を、縦横比を維持したままプレビューに表示する。
- 横長画像では横幅を活かしたプレビュー領域、縦長画像では画像に合わせたコンパクトな縦長プレビュー領域を使用する。縦長画像で不要な左右の余白を表示しない。
- 切り抜き比率は横16:9または縦9:16から選択する。
- 横長の画像を読み込んだ場合は横16:9、縦長の画像を読み込んだ場合は縦9:16を初期選択する。
- 残す範囲は選択した比率に固定された選択枠で示す。
- 選択枠はドラッグで移動でき、辺または四隅のハンドルで拡大・縮小できる。
- 選択枠が画像の外に出たり、選択中の比率以外になったりしてはならない。
- 初期状態では、画像の中央に収まる最大の選択比率の領域を選択する。
- 切り抜き比率を切り替えた場合は、選択範囲を中央に収まる最大領域へ戻す。
- 縦9:16では、選択枠のリサイズ操作は上下のハンドルのみで行う。縦方向の調整に応じて、横幅は選択枠の中央を基準に自動調整する。

## コピーライト表記

利用者は次のいずれかを選択する。

| 表示名 | 表記 |
| --- | --- |
| コピーライトなし（非推奨） | 表示しない |
| 簡易表記 | `© SQUARE ENIX` |
| 標準表記 | `(C) SQUARE ENIX CO., LTD. All Rights Reserved` |

- 配置は左上、右上、左下、右下から選択する。
- フォントは4種類から選択する。
- 文字サイズは、初期値を最大値とする縮小専用スライダーで40%から100%の間を選択する。
- コピーライトなしを選択した場合は、プレビュー・出力画像のどちらにも文字を描画しない。ゲーム側ですでに表記される場合を想定した選択肢であり、権利表記が必要な画像では選ばないことを推奨する。
- 文言、配置、フォント、文字サイズの変更はプレビューへ即時に反映する。

## 生成とダウンロード

- 出力モードは「通常（1枚）」と「横3分割（3枚）」から選択する。
- 横3分割を選択した場合は、選択枠へ等間隔のガイド線2本を表示する。
- 「トリミングしてPNGを生成」または「3枚のPNGを生成」を押すと、選択範囲とコピーライト設定を確定してPNGを生成する。
- 出力画像の解像度は、プレビューではなく元画像に対応する選択範囲のピクセル数を使用する。
- 横3分割では、完成した横16:9または縦9:16画像を横幅で均等に分割し、左・中央・右の順に3枚のPNGを生成する。端数のピクセルは隣接する画像の境界で調整し、欠けや重複がないようにする。
- コピーライトは完成した画像へ描画してから分割する。そのため、コピーライトが入るのは選択した位置に対応する1枚のみとなる。
- PNGは可逆圧縮で出力し、アプリの出力処理で追加の非可逆圧縮は行わない。
- JPEG入力に元から含まれる圧縮による品質は回復しない。
- 生成後はトリミングボタンを非活性にし、通常モードでは1つ、横3分割モードでは左・中央・右に対応する3つのダウンロードボタンを表示する。
- ダウンロードするPNGのファイル名には生成日時を含める。横3分割モードでは、末尾に`-1`、`-2`、`-3`を付けて左・中央・右の順を示す。
- 選択範囲またはコピーライト設定を変更すると生成結果を無効にし、再生成できる状態に戻す。

## 対象外

- 横16:9および縦9:16以外のトリミング比率
- 複数画像の一括処理
- 明るさ、色、フィルターなどの画像編集
- 画像の保存や共有
- スマートフォン・タブレット向けの操作最適化
